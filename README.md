# quiz-bot
Чтобы бот работал, установите все библиотеки, указанные в файле requirements.txt (самый простой способ: ```pip install -r requirements.txt --break-system-packages```) и укажите в переменной ```TOKEN``` токен вашего бота. Получить токен можно у бота BotFather
**ВАЖНО:** Если вы собираетесь поделиться кодом с кем-то - ОБЯЗАТЕЛЬНО УБЕРИТЕ ТОКЕН ИЗ ПЕРЕМЕННОЙ ```TOKEN```
